# study-codingtest

TypeScript로 코딩테스트 문제를 풀고 기록하는 레포.

## 구조

- `ts-programmers/` — 프로그래머스 (level0~2 + 유형별: dfs-bfs, hash, stack-queue, exhaustive)
- `ts-leetcode/` — LeetCode (easy, medium)
- `deep-logic/` — 내장 함수/Promise 직접 구현
- `algorithm/` — 강의/책 실습

## 실행

```sh
npx tsx <파일경로>
```
